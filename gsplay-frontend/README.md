# GSPlay frontend

The React/Vite client lives in `src/`, with member screens in `src/pages/`, reusable UI in
`src/components/`, API access in `src/services/`, and responsive Playwright scenarios in `e2e/`.

Member-facing copy uses GSPlay's playful Roman-flavoured Italian voice. Keep controls and status
labels clear while giving headings, introductions, empty states, confirmations, and recoverable
errors the same personality as Home, Catalogue, Game Detail, and Casual Friday. Admin and helper
workflows remain concise and operational.

See the repository-level [`AGENTS.md`](../AGENTS.md) for the authoritative project guidelines and
commands.
